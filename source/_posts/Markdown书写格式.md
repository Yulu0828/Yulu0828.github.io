Markdown 是一种用纯文本符号表示排版的标记语言，文件通常以 `.md` 为后缀。下面是一份通用语法速查，适用于笔记、技术文档、项目说明等场景。

不同软件支持的 Markdown 扩展略有差别；表格、任务列表、删除线等功能需要编辑器支持。

## 1. 标题
使用 `#` 表示标题层级，支持一至六级。`#` 后面加一个空格。

```plain
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

建议按层级递进，避免从一级直接跳到四级。

## 2. 段落与换行
**段落之间空一行：**

```plain
这是第一段。

这是第二段。
```

**同一段内强制换行：**在行尾添加两个空格，再按回车；也可以使用编辑器支持的 `<br>`。

只按一次回车，在不同软件中可能显示为空格或换行。

## 3. 文字强调
| 效果 | 写法 |
| --- | --- |
| _斜体_ | `*斜体*` |
| **粗体** | `**粗体**` |
| _**粗斜体**_ | `***粗斜体***` |
| ~~删除线~~ | `~~删除线~~` |


下划线也可以表示强调，例如 `_斜体_`、`__粗体__`。

## 4. 列表
**无序列表：**

```plain
- 苹果
- 香蕉
- 橙子
```

也可以使用 `*` 或 `+`，同一列表中建议统一符号。

**有序列表：**

```plain
1. 第一步
2. 第二步
3. 第三步
```

**嵌套列表：**

```plain
- 第一类
    - 子项目 A
    - 子项目 B
- 第二类
    - 子项目 C
```

通过缩进表示层级，嵌套内容要与所属列表项对齐。

**任务列表（扩展语法）：**

```plain
- [x] 已完成
- [ ] 未完成
```

## 5. 引用
使用 `>`，可以包含多段文字或嵌套引用。

```plain
> 这是一段引用。
>
> 这是引用的第二段。
>
> > 这是嵌套引用。
```

## 6. 链接
**普通链接：**

```plain
[显示文字](https://example.com)
```

**带提示文字的链接：**

```plain
[显示文字](https://example.com "鼠标悬停时的提示")
```

**直接显示网址：**

```plain
<https://example.com>
```

**引用式链接：**适合多次引用同一地址。

```plain
请查看[官方文档][docs]。

更多信息也可以参考[这里][docs]。

[docs]: https://example.com/docs
```

## 7. 图片
图片语法比链接多一个 `!`：

```plain
![图片的替代说明](图片地址)
```

例如：

```plain
![山间日出](https://example.com/sunrise.jpg)
```

也可以使用相对路径：

```plain
![山间日出](./images/sunrise.jpg)
```

相对路径如何解析取决于使用的平台。分享文档时，需要同时保留图片文件和正确的目录关系。

标准 Markdown 没有统一的图片尺寸设置语法；调整大小通常需要编辑器扩展或 HTML。

## 8. 代码
**行内代码：**使用一对反引号。

```plain
使用 `print()` 输出内容。
```

**代码块：**使用三个反引号包围，可以在开头标注语言。

```plain
```python
name = "Markdown"
print(name)
```
```

渲染效果：

```plain
name = "Markdown"
print(name)
```

展示包含三个反引号的文本时，外层可以使用四个反引号。

## 9. 分隔线
单独一行写三个或更多的 `-`、`*` 或 `_`：

```plain
上一部分内容。

---

下一部分内容。
```

建议前后空行，避免与其他语法混淆。

## 10. 表格（扩展语法）
用 `|` 分隔列，用 `-` 分隔表头和正文：

```plain
| 名称 | 类型 | 数量 |
|---|---|---|
| 苹果 | 水果 | 3 |
| 胡萝卜 | 蔬菜 | 5 |
```

使用冒号设置对齐方向：

```plain
| 左对齐 | 居中 | 右对齐 |
|:---|:---:|---:|
| 内容 A | 内容 B | 100 |
```

单元格中需要显示竖线时，可以写成 `\|`。

## 11. 转义字符
如果想显示符号本身，而不是让它产生排版效果，可以在前面加反斜杠 `\`。

```plain
\*这段文字不会变成斜体\*

\# 这行不会变成标题
```

显示为：

```plain
*这段文字不会变成斜体*

# 这行不会变成标题
```

## 12. 常见扩展功能
下面这些**不是所有 Markdown 软件都支持**，跨平台使用时需要确认。

**脚注：**

```plain
这段话需要补充说明。[^1]

[^1]: 这里是脚注内容。
```

**数学公式：**

```plain
行内公式：$E = mc^2$

独立公式：

$$
a^2 + b^2 = c^2
$$
```

**HTML 注释：**在允许该语法的平台上，通常不会出现在渲染后的正文中，但源文件中仍然可见。

```plain
<!-- 这里是注释，不要存放密码等敏感信息。 -->
```

**YAML 元数据：**部分笔记、博客和文档工具支持文件顶部的配置，但它不是通用 Markdown 正文语法。

```plain
---
title: 文档标题
author: 作者
---
```

## 常用写法速查
| 用途 | 写法 |
| --- | --- |
| 标题 | `## 标题` |
| 粗体 | `**文字**` |
| 斜体 | `*文字*` |
| 无序列表 | `- 内容` |
| 有序列表 | `1. 内容` |
| 引用 | `> 内容` |
| 链接 | `[文字](地址)` |
| 图片 | `![说明](地址)` |
| 行内代码 | ``代码`` |
| 分隔线 | `---` |
| 任务列表 | `- [ ] 内容` |
| 转义 | `\*` |


日常书写时，保持**段落之间空行、标记后留空格、列表缩进一致、文件使用 UTF-8 编码**，通常就能获得清晰且兼容性较好的排版。
